# docs/ — Project Documentation

Professional documentation for the DeliveryApp project.  
All documentation lives here so developers never need to dig through source code to understand the project.

---

## Structure

```
docs/
├── api/                   # External API endpoint contracts & examples
├── architecture/          # Architecture Decision Records (ADRs)
├── guides/
│   ├── setup/             # Step-by-step environment & project setup
│   ├── contributing/      # PR process, commit conventions, code style
│   └── deployment/        # iOS App Store & Android Play Store releases
├── design/
│   ├── screens/           # Screen-level design specs & mockups
│   └── components/        # Component design specs
└── changelog/             # Version history & release notes
```
